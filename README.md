# Papers CHVN

Registro personal de producción académica en HTML, CSS y JavaScript.

## Uso local

Abre `index.html` en un navegador. Los registros se guardan en el almacenamiento local del navegador. Usa **Exportar** con regularidad para crear respaldos JSON e **Importar** para restaurarlos.

## Próxima etapa

Al publicar el proyecto conectaremos una base de datos para que los registros sean persistentes entre dispositivos y estén protegidos por autenticación.

## Railway

El proyecto incluye un servidor Node.js sin dependencias externas y la configuración necesaria para desplegarse directamente en Railway.
